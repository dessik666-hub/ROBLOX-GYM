# Neon Gym Simulator — прототип зала

Симулятор качка по мотивам референс-видео, в неоновом стиле из `docs/gdd.md`. Музыки нет.

## Запуск

Проект на Rojo: код лежит в файлах, зал строится скриптом.

1. Установите [Rojo](https://rojo.space) и плагин Rojo в Roblox Studio.
2. В папке проекта выполните `rojo serve`, в Studio нажмите **Connect**.
   Или соберите файл места: `rojo build -o NeonGym.rbxlx`.
3. В Studio: **Game Settings → Avatar → Avatar Type: R15**. На R6 позы будут грубыми и тело не будет расти.
4. Для сохранения прогресса в Studio: опубликуйте место и включите **Game Settings → Security → Enable Studio Access to API Services**. Без этого игра работает, но прогресс не сохраняется.

## Как играть

- Подойди к тренажёру и нажми **Тренироваться** (E или тап по подсказке). Персонаж садится или ложится на тренажёр.
- **Силовые тренажёры:** тапай или кликай по экрану — каждый тап это повтор. Внизу набирай блины 1/2/5/20/50/100 фунтов кнопками − и +, до 10 штук.
- **Беговая дорожка и гребля:** бег идёт сам. Внизу выбираешь скорость от 3 до 50 миль/ч.
- Выйти с тренажёра: кнопка **Выйти** или **Q**.

## Механики

| Механика | Как работает |
| --- | --- |
| 6 статов | Выносливость, Грудь, Пресс, Спина, Руки, Ноги. Каждый тренажёр качает свою мышцу (верхняя панель, как в видео). |
| Сила | Сумма всех статов. Видна над головой и открывает новые тренажёры. |
| Вес и «Рекомендуется» | Блин нужного веса можно поднять, только если стат мышцы ≥ (вес − 1)². Строка внизу зелёная или красная. Слишком тяжело — повтор срывается. |
| Выносливость (кольцо ❤) | Каждый повтор тратит выносливость: тяжелее вес — больше трата. Восстанавливается через 1 с отдыха. Максимум = 50 + стат «Выносливость». |
| Бег | Дорожка и гребля качают стат «Выносливость» каждую секунду. Быстрая скорость даёт больше, но требует набранной выносливости. Гребля даёт ×2 и открывается позже. |
| Ранги | 8 рангов от «Новичка» до «Неонового титана». Для повышения каждый стат должен дойти до порога. Ранг даёт +10…80% к росту. |
| Рост тела | Чем больше Сила, тем шире персонаж (R15). |
| Авто-тренировка | 2 повтора в секунду — медленнее, чем тапать (как в GDD). Пока бесплатна; позже её закроет геймпасс. |
| NPC | Администратор Лана на ресепшене здоровается и подсказывает. Тренер Макс ходит к тем, кто тренируется, и подбадривает. |

### Своё (нет в видео)

- **Неоновый пампинг.** Повторы подряд без пауз дольше 1,2 с дают +2% за повтор, до +50%.
- **Идеальный вес.** Если вес близок к твоему пределу (требование ≥ 75% стата), повтор даёт +50%. Выгодно брать тяжёлый вес, а не жать 1 фунт.
- **Гребной тренажёр** как вторая кардио-машина с позой гребли и ездящим сиденьем.
- **Неоновый комплекс «Титан»** — толчок штанги над головой, качает все пять мышц сразу.

Бонусы складываются, а не перемножаются (правило GDD).

## Анимации

Анимационные ассеты не нужны: позы задаются кодом через суставы (`Motor6D.Transform`) в `src/shared/Poses.lua`. У каждого тренажёра своя поза и своё движение: подъём гантелей, жим лёжа, скручивания, жим ногами, тяга блока, присед, сведение в кроссовере, толчок «Титана», бег, гребля. Вместе с телом двигаются детали тренажёра: штанга, платформа, ручки, лента дорожки, сиденье гребли. Все игроки видят анимации друг друга.

## Структура

```
src/shared/Config.lua        все числа: статы, тренажёры, блины, скорости, ранги
src/shared/Poses.lua         позы и движения для каждого тренажёра
src/server/Main.server.lua   логика на сервере: повторы, бег, выносливость, ранги, синхронизация
src/server/World.lua         зал: зоны, ресепшен, стеклянная стена, подиум, расстановка тренажёров
src/server/MachineModels.lua модели тренажёров из деталей
src/server/Data.lua          сохранение с повторами и защитой от затирания
src/server/Body.lua          табличка над головой и рост тела
src/server/Npcs.lua          администратор и тренер
src/client/Main.client.lua   ввод, метки над тренажёрами, всплывающие числа
src/client/Hud.lua           интерфейс
src/client/TrainAnimator.lua анимации тела и тренажёров
src/client/Popups.lua        всплывающие «+N»
```

## Баланс

Модель идеальной игры (3 повтора в секунду, лучший вес, бег, когда кончилась выносливость):

| Ранг | Время |
| --- | --- |
| Начинающий | ~1 мин |
| Любитель | ~4 мин |
| Сильный парень | ~10 мин |
| Атлет | ~20 мин |
| Качок | ~45 мин |
| Чемпион зала | ~1,5 ч |
| Неоновый титан | ~4 ч |

С паузами это 6–8 часов реальной игры, как в GDD. Числа предварительные, нужен плейтест.

## Чего пока нет

Питомцы и яйца, магазин и геймпассы, колесо удачи, награды, телепорты в другие залы, подиум и агентства, перерождение. Всё это из видео или GDD, но в эту задачу не входило.
